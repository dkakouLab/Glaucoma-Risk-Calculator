# Glaucoma-Risk-Calculator

This 5-Year Primary Open-Angle Glaucoma (POAG) Risk Calculator is based on results from the **Ocular Hypertension Treatment Study (OHTS)**. It estimates the 5-year risk that an individual with ocular hypertension will develop POAG.

Predictions are most accurate for patients who are similar to those enrolled in the OHTS.

You may choose a clinical-only model or include genetic markers (TMCO1, CDKN2B-AS1, ADAMTS18/NUDT7, PLCE1, GABRG2) if available.

summary_analysis.Rmd contains all preliminary analysis performed prior to creating risk calculator.
